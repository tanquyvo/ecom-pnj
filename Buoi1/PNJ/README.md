### **1\. Giới thiệu bài tập**

Bài tập cá nhân Buổi 2 tiếp tục phát triển website đã thực hiện ở Buổi 1, tập trung vào việc hoàn thiện cấu trúc HTML và cải thiện giao diện bằng CSS.

Thông qua bài tập, sinh viên thực hành các kỹ thuật HTML5 và CSS3 cơ bản nhằm nâng cao tính tổ chức của mã nguồn, khả năng trình bày giao diện và trải nghiệm người dùng trên website.

- **Tên dự án:** Website PNJ
- **Website tham khảo:** pnj.com.vn

### **2\. Website tham khảo và khu vực cải tiến**

Website được phát triển dựa trên giao diện tham khảo từ pnj.com.vn.

**Khu vực đã cải tiến:**

- **Thanh điều hướng (Navigation):** Hoàn thiện cấu trúc và cách bố trí các thành phần điều hướng trên website.
- **Khu vực tìm kiếm và bộ lọc sản phẩm:** Tổ chức lại biểu mẫu tìm kiếm và các thành phần lọc nhằm hỗ trợ người dùng tìm kiếm sản phẩm.
- **Khu vực hiển thị sản phẩm:** Cải thiện cấu trúc thẻ sản phẩm và bố cục danh sách sản phẩm bằng CSS Grid/Flexbox.
- **Nút chức năng:** Điều chỉnh cách trình bày và bổ sung hiệu ứng tương tác cho nút "Xem chi tiết".
- **Giao diện responsive:** Kiểm tra và điều chỉnh bố cục để cải thiện khả năng hiển thị trên các kích thước màn hình khác nhau.

### **3\. Kỹ thuật HTML5/CSS3 đã thực hành**

Trong quá trình thực hiện, bài tập áp dụng các kỹ thuật sau:

**HTML5**

- Sử dụng các thẻ Semantic HTML5 để tổ chức cấu trúc nội dung.
- Xây dựng các thành phần như điều hướng, biểu mẫu tìm kiếm, bộ lọc và thẻ sản phẩm.
- Sử dụng các thẻ form, fieldset, legend, article, label nhằm tăng tính ngữ nghĩa và khả năng truy cập.

**CSS3**

- Tổ chức và liên kết CSS ngoài với HTML.
- Sử dụng các CSS Selector: Element, Class và Descendant.
- Áp dụng Box Model thông qua margin, padding, border và border-radius.
- Sử dụng Flexbox và/hoặc CSS Grid để bố trí các thành phần giao diện.
- Thực hành các hiệu ứng hover, transition và focus-visible.
- Sử dụng Media Query để điều chỉnh giao diện trên các kích thước màn hình khác nhau.

### **4\. Hướng dẫn chạy website**

1. Tải hoặc clone repository về máy tính.
2. Mở thư mục dự án bằng Visual Studio Code hoặc trình soạn thảo mã nguồn tương ứng.
3. Mở file index.html bằng trình duyệt web để xem giao diện.
4. Có thể sử dụng tiện ích Live Server trong Visual Studio Code để chạy website thuận tiện hơn.

### **5\. Những thay đổi đã thực hiện**

So với phiên bản Buổi 1, website đã được điều chỉnh và cải thiện các nội dung sau:

- **Cấu trúc HTML:** Tổ chức lại mã HTML bằng các thẻ Semantic HTML5 như nav, aside, article và form. Bổ sung cấu trúc cho các thành phần như thanh điều hướng, bộ lọc sản phẩm, biểu mẫu tìm kiếm và thẻ hiển thị sản phẩm nhằm tăng tính rõ ràng và ngữ nghĩa của nội dung.
- **Bố cục và trình bày CSS:** Hoàn thiện cách tổ chức CSS, áp dụng các CSS Selector và Box Model để điều chỉnh khoảng cách, đường viền và kích thước các thành phần. Sử dụng Flexbox và CSS Grid để sắp xếp bố cục, cải thiện cách hiển thị danh sách sản phẩm và các nút chức năng.
- **Các thành phần tương tác:** Bổ sung hiệu ứng hover, transition cho các thành phần giao diện, đặc biệt là nút "Xem chi tiết". Đồng thời, sử dụng focus-visible nhằm cải thiện khả năng nhận biết trạng thái tương tác khi sử dụng bàn phím.
- **Khả năng hiển thị trên thiết bị di động:** Kiểm tra giao diện bằng Chrome DevTools ở nhiều kích thước màn hình. Điều chỉnh bố cục bằng Flexbox và Media Query nhằm hạn chế tình trạng các thành phần trong header, thanh tìm kiếm và biểu tượng bị tràn hoặc lệch vị trí trên màn hình nhỏ, đồng thời duy trì bố cục trên phiên bản desktop.
